# /shared/types — team contracts

Do not edit anything here unless the user explicitly asks you to change a contract in this session. Every other folder depends on these shapes.

These are a **v0 draft**. The game design isn't final, so expect the team to revise them together once it is (James's Night Relay kit is the reference).

When a change is approved:
- Prefer **adding** an optional field over renaming or removing one.
- Update every producer and consumer in the same merge, or tell the user which owners need to follow up.
- Run `npm run check`.
