# LOCK IN deterministic simulation

`src/game/` owns local rules and the shared state contract. Current number-line rules supersede the older graph-chase safety windows in the preserved build kits. Tune the live game in `config.ts`; do not edit archived kit files or the cutscene work. See [the balance specification](../../docs/BALANCE.md) for formulas and defaults.

- Public API remains `createGame(seed, mode)`, `dispatch(state, action)`, and `step(state, dtSeconds)`. One fixed 30 Hz clock owns active game time. Pause freezes it. The tutorial has no lethal movement, scares, protocol timeout, or finite isolation-charge consumption. Providers never block input or simulation.
- `creature.linePosition` is the authoritative integer, from zero at the shelter wall to `config.line.length` at the far end. Position starts at 18. The first scheduled step follows the 25-second opening grace plus the 2.5-second interval. A separate seeded movement RNG chooses a step from −3 through +3, then clamps to the line. Vec3, node, camera silhouettes, sound and motion captions are projections of that same position; they must not own another monster or teleport it.
- The distance detector is display-only. `sensorDistance` samples the line position every `config.line.sensorSeconds` (4 seconds), and `sensorSampleAt` is active game time. Equipment off clears the reading immediately. These are not biometric measurements and are not sent to providers. Normal HUD must not replace this delayed reading with hidden authoritative position. Consenting judge trace may show the real public game position.
- Danger is a bounded 0–100 game value combining time, mistake pressure, completed work, accepted coarse physiological trend and prior isolation use. Mistakes add pressure; completed faults, wire connections and stages relieve it. Missing/manual/rejected physiology is neutral. Pressure affects step weights, not hidden scene actors or direct death commands. It is fictional game difficulty, never a fear or medical score.
- Stages remain: 8 faults plus 4 wire connections; 5 memory inputs and emitter A; 12 faults plus 4 new wire connections; 6 memory inputs and emitter B; then final containment broadcast. Memory uses 0.42-second pulses, 0.16-second gaps and a 16-second response window. Tutorial memory has 4 inputs. Wire target order, connections, memory sequence and player inputs remain private local puzzle state. Public wire events reveal only success or `WRONG_INPUT WIRE`, never colors/endpoints/answers.
- Q has 4 finite charges in standard play. It isolates equipment for 10 seconds and changes only the probabilities at the next normal 2.5-second movement tick; it never moves the creature immediately. Its retreat bias is 0.90 minus 0.20 times normalized danger. Manual restoration becomes available after 8 seconds; otherwise power returns at 10 seconds, followed by 10 seconds of relay cooldown. Restoring an unrelated blackout does not create or extend that cooldown. Isolation preserves puzzle progress but pauses research. Repeated Q cannot refresh it, and cooldown/exhaustion cannot grant free uses. Tutorial isolation is separate and repeatable.
- The proximity alarm latches at line position ≤7 and clears at ≥10. It follows authoritative movement even while power is off. A strike can commit only at position ≤1 after the required warning interval and fresh audible evidence. After commitment, Q, F, lures and model results cannot cancel the 2.4-second windup. Pulse alone never satisfies the audible evidence gate. There is no visible rescue countdown.
- Earned lures override normal and model bias toward their configured far-end target for their bounded lifetime. The final containment lure lasts until resolved and cannot sample a negative step. Arrival at 24 followed by the configured three-second seal wins. The 300-second active-time deadline otherwise ends the run. These rules are independent of provider completion time.
- Gemini proposes the existing exact tactic/target/taunt schema. The local reducer maps an accepted tactic to a bias of at most ±0.15 for 8 seconds. It never accepts a proposed position, step, probability, random value, timer or attack. Validate shape, request/state identity, eight-second expiry, evidence, allowed pair, taunt eligibility and duplicates. Record accepted live, fallback and rejected/stale results separately.
- `state.scare` remains a local event ID, game timestamp and impact/monitor/breach kind. Opening grace and tutorial suppress scares and contextual taunts. Later nonfatal scares and taunts obey configured/capped spacing. Audio uses one reserved speech queue: an in-flight response cannot interrupt an instruction. The current tutorial has no provider narration; any future tutorial speech must use that same scheduler.
- Public observations add only `linePosition`, `lineLength`, `danger`, and `quietChargesRemaining`. Trace schema is `lock-in-v2`; it includes no raw pulse, native sample clocks, camera frames, report history, RNG state, wire solution or memory answer. No agent should provision Convex through the CLI.
- Test multiple seeded wins and losses, grace, finite isolation, movement probabilities, delayed detector, strict model limits, puzzle privacy, pause, quiet/blackout continuity, and async resource cleanup. Browser evidence must use visible controls and label synthetic fixtures separately from live providers. Preserve credentials and cutscene files.
