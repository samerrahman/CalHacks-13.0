# LOCK IN deterministic simulation

`src/game/` owns local rules and the shared state contract. Current number-line rules supersede the older graph-chase safety windows in the preserved build kits. Tune the live game in `config.ts`; do not edit archived kit files or the cutscene work. See [the balance specification](../../docs/BALANCE.md) for formulas and defaults.

- Public API remains `createGame(seed, mode)`, `dispatch(state, action)`, and `step(state, dtSeconds)`. One fixed 30 Hz clock owns active game time. Pause freezes it. The tutorial has no lethal movement, scares, protocol timeout, or finite isolation-charge consumption. Providers never block input or simulation.
- `creature.linePosition` is the authoritative integer, from zero at the shelter wall to `config.line.length` at the far end. Position starts at 18. The first scheduled step follows the 25-second opening grace plus the 2.5-second interval. A separate seeded movement RNG chooses a step from −3 through +3, then clamps to the line. Vec3, node, camera silhouettes, sound and motion captions are projections of that same position; they must not own another monster or teleport it.
- The distance detector is display-only. `sensorDistance` samples the line position every `config.line.sensorSeconds` (4 seconds), and `sensorSampleAt` is active game time. Equipment off clears the reading immediately. These are not biometric measurements and are not sent to providers. Normal HUD must not replace this delayed reading with hidden authoritative position. Consenting judge trace may show the real public game position.
- Danger (shown as EXPOSURE) is a bounded 0–100 game value combining time, work noise (`state.pressure`), accepted coarse physiological trend and prior isolation use. Running equipment is loud: while powered with a live research task, machinery noise never drops below `tasks.equipmentNoise`, every correct input and active fault adds more, mistakes add more still; it cools only with the equipment off (six times faster while isolated) and a completed stage relieves it. `huntWindow`/`huntActive` derive seeded hunts (one per `hunt.periodSeconds`) from the seed and time alone; isolation and lures override them. `dangerParts` exposes the named parts the HUD shows. Low exposure drifts the creature away; high exposure rushes it. After 8 seconds without audible evidence it loses the trail and drifts outward. Missing/manual/rejected physiology is neutral. It is fictional game difficulty, never a fear or medical score.
- `tasks.step` names the live part of each stage. Stage 1: rack sound key then 6 faults found by ear (`faultSounds` shuffles the four sounds per stage from the seed; `listenFrom` times the key and blocks spawns), 6 cables (six-cable panels), conduit (1 board; `RoutingState` holds tile kinds, turns and a private answer). Stage 2: memory growing 3→5, heartbeat mask, emitter A. Stage 3: new key, 8 faults by ear with two at once, 12 cables, locate (3 monitor marks). Stage 4: memory growing 4→6, calm hold, emitter B. Then final containment. Tutorial memory stays at 4 and skips the thinking tasks. Heartbeat mask and calm hold read only the coarse accepted trend (ELEVATED makes them harder/slower, STEADY speeds calm); manual or missing data uses the standard rule, so every task runs without a camera. Wire, routing, pulse and memory answers remain private local puzzle state. Public events reveal only success or `WRONG_INPUT <kind>`, never answers. See BALANCE.md for every rule.
- Q has 3 finite charges in standard play; each completed research stage recharges one (capped at 3). It isolates equipment until the player restores it (hold F once the restore window opens at 4 s) or the 25-second cap, and changes only the probabilities at the next normal 2.5-second movement tick; it never moves the creature immediately. Its retreat bias is 0.55 minus 0.20 times normalized danger, so it lingers. Manual restoration becomes available after 4 seconds; otherwise power returns at 25 seconds, followed by 10 seconds of relay cooldown. Restoring an unrelated blackout does not create or extend that cooldown. Isolation preserves puzzle progress but pauses research. Repeated Q cannot refresh it, and cooldown/exhaustion cannot grant free uses. Tutorial isolation is separate and repeatable.
- The near state (still the `PROXIMITY_ALARM` event and `alarmLatched`) latches at line position ≤7 and clears at ≥10; it is heard as close footsteps and captions, not a siren. `creatureBearing(seed, time)` is a stateless smooth drift around the shelter used for the heard position, captions and the radar; CCTV keeps the path projection. It follows authoritative movement even while power is off. A strike can commit only at position ≤1 after the required warning interval and fresh audible evidence. After commitment, Q, F, lures and model results cannot cancel the 2.4-second windup. Pulse alone never satisfies the audible evidence gate. There is no visible rescue countdown.
- Earned lures override normal and model bias toward their configured far-end target for their bounded lifetime. The final containment lure lasts until resolved and cannot sample a negative step. Arrival at 24 followed by the configured three-second seal wins. The 480-second (8-minute) active-time deadline otherwise ends the run. These rules are independent of provider completion time.
- Gemini proposes the existing exact tactic/target/taunt schema. The local reducer maps an accepted tactic to a bias of at most ±0.15 for 8 seconds. It never accepts a proposed position, step, probability, random value, timer or attack. Validate shape, request/state identity, eight-second expiry, evidence, allowed pair, taunt eligibility and duplicates. Record accepted live, fallback and rejected/stale results separately.
- `state.scare` remains a local event ID, game timestamp and impact/monitor/breach kind. Opening grace and tutorial suppress scares and contextual taunts. Later nonfatal scares and taunts obey configured/capped spacing. Audio uses one reserved speech queue: an in-flight response cannot interrupt an instruction. The current tutorial has no provider narration; any future tutorial speech must use that same scheduler.
- Public observations add only `linePosition`, `lineLength`, `danger`, and `quietChargesRemaining`. Trace schema is `lock-in-v2`; it includes no raw pulse, native sample clocks, camera frames, report history, RNG state, wire solution or memory answer. No agent should provision Convex through the CLI.
- Test multiple seeded wins and losses, grace, finite isolation, movement probabilities, delayed detector, strict model limits, puzzle privacy, pause, quiet/blackout continuity, and async resource cleanup. Browser evidence must use visible controls and label synthetic fixtures separately from live providers. Preserve credentials and cutscene files.
